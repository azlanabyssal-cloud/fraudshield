# Fonts

Self-hosted copies of three Google Fonts families, so the site makes no request to Google to draw a page:

- DM Sans (body)
- Playfair Display (headlines)
- JetBrains Mono (labels and numbers)

All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Only the Latin and Latin-extended subsets are kept; the rupee sign is in Latin-extended. The files are variable fonts, so one file covers every weight in `fonts.css`.
